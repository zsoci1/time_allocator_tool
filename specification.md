- a tool for keeping track of tasks like a TODO list and allocating time to them based on the free time avaliable on that given day
- keeps track of current time 
- can create different categories and subcategories with todo tasks inside
- possible to set reccuring tasks, for exp. weekly tasks like aquarium maintenance, once it was checked off for that week it gets crossed out and goes into a dropdown list which is hidden by default, these reccuring tasks can be in categories like monthly weekly etc.. tasks that were not completed on the given week will show a missed last week sign upon the cursor hovering over it
- there is a different panel/page for allocating time for the current day, the user can allocate time to the tasks chosen from the categories. the tool keeps track of the allocated time, saves it in a database and creates a chart breakdown (different panel) with daily, weekly, monthly and yearly stats.
- one of the main goals with this is to utilize available time efficiently and avoid procrastination by doing pseudo-productive tasks instead (like editing a github profile readme or optimizing the layout of the notes which can seem productive but in reality its just avoiding the harder tasks)
- tasks have different priorities, users can customize the color and styling option for the text (task) and can set different presets with names for them. 
- desktop tool/app built for windows
- tracking of the time allocated in the stats page shows the category in which the given task was in, while when allocating the available free time the user chooses a specific task
